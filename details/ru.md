# CLIProxyAPI для DeepSeek Harness

Откройте **Plugins** и выберите **CLIProxyAPI**. Выберите протокол обмена, который предоставляет шлюз (OpenAI Responses, OpenAI Chat Completions, Anthropic Messages или Google Generative AI), затем укажите фактический адрес и явно выберите действие с авторизацией: сохранить, заменить ключ, использовать ссылку или отключить авторизацию. HTTP не шифруется. Повторное использование ключа с новым адресом требует согласия.

Загрузите предпросмотр, найдите и выберите модели; массовые действия применяются ко всему каталогу. Сохранение включает адрес, авторизацию, политику и выбор. Ноль моделей допустим, но подключение не готово. Детали содержат метаданные, источник возможностей и заявленные уровни рассуждения. При ошибке обновления прежний каталог может быть показан как устаревший. Сохранение и активация показываются отдельно.

Отключение сохраняет настройки и ключ; удаление ключа выполняется отдельно. При сохранении первого подключения прежняя запись принимается автоматически с обратимой резервной копией; **Импорт прежнего подключения** по-прежнему доступен для явного импорта. Изучите ошибки восстановления перед повтором. Не восстанавливайте старую копию поверх новых настроек.

Внизу Models можно открыть Plugins и затем выбрать CLIProxyAPI. Это не полноценная управляемая строка Models. После установки или обновления перезапустите DSH. Требуются Node от 24.9.0 и DSH 0.2.2-rc.2; `engines.dsh` допускает остальную линию 0.2.x.
