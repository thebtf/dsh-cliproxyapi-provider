# CLIProxyAPI для DeepSeek Harness

Плагин подключает CLIProxyAPI через OpenAI Responses API и автоматически загружает и обновляет список доступных моделей.

## Настройка

1. Вернитесь на страницу **Плагины** и в разделе **Встроенные настройки плагинов** выберите **CLIProxyAPI**. Это отдельный пункт, не карточка установленного пакета.
2. Укажите **Base URL** вашего сервера, например `http://127.0.0.1:8317/v1`, и API-ключ. Если сервер не требует ключ, оставьте поле пустым.
3. Нажмите **Load models**. Найдите модели по имени или ID; кнопка **Deselect all loaded models** позволяет снять все галочки и выбрать только нужные модели. В строках показаны лимиты, типы входа и reasoning efforts; в **Model details → All CPA fields** доступны все поля ответа CPA. Нажмите **Save & Enable** и дождитесь подтверждения синхронизации. После этого выберите модель в чате.

После установки или обновления полностью перезапустите DeepSeek Harness. Плагин предназначен для DSH `0.2.2-rc.1`.

Плагин использует встроенный адаптер `llm-pi-ai`: он не изменяет состав истории или инструментов, отправляемых модели.
