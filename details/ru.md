# CLIProxyAPI для DeepSeek Harness

Откройте **Plugins** и выберите **CLIProxyAPI**. Выберите протокол обмена, который предоставляет шлюз (OpenAI Responses, OpenAI Chat Completions, Anthropic Messages или Google Generative AI), затем укажите фактический адрес сервера и явно выберите действие с авторизацией: сохранить, заменить ключ, использовать ссылку или отключить авторизацию. Завершающий `/v1` можно не писать: каталог в любом случае читается из `{root}/v1/models`, а каждый протокол получает адрес, который добавляет его SDK. HTTP не шифруется. Повторное использование ключа с новым адресом требует согласия.

Загрузите предпросмотр, найдите и выберите модели; массовые действия применяются ко всему каталогу. Сохранение включает адрес, авторизацию, политику и выбор. Ноль моделей допустим, но подключение не готово. Детали содержат метаданные, источник возможностей и заявленные уровни рассуждения. При ошибке обновления прежний каталог может быть показан как устаревший. Сохранение и активация показываются отдельно.

Отключение сохраняет настройки и ключ; удаление ключа выполняется отдельно. При сохранении первого подключения прежняя запись принимается автоматически с обратимой резервной копией; **Импорт прежнего подключения** по-прежнему доступен для явного импорта. Плагин также хранит копию последнего сохранённого подключения вне профиля: если запись настроек исчезла после пересборки профиля или блокировки по совместимости, кнопка **Восстановить сохранённое подключение** вернёт её без повторного ввода адреса и ключа. Изучите ошибки восстановления перед повтором. Не восстанавливайте старую копию поверх новых настроек.

Внизу Models можно открыть Plugins и затем выбрать CLIProxyAPI. Это не полноценная управляемая строка Models. После установки или обновления перезапустите DSH. Требуются Node от 24.9.0 и DSH 0.2.2-rc.3; `engines.dsh` допускает остальную линию 0.2.x.
